# FriendAway Growth + Production Plan

## Phase A: Media and engagement
- Add native photo/video uploads via Supabase Storage signed uploads.
- Ship likes, saves, reposts, and post sharing.
- Add city-trending and newcomer-trending feed sections.

## Phase B: Trust and safety
- Add report queues for post/comment/user.
- Add block/mute user controls.
- Add moderation roles for communities.

## Phase C: Retention loops
- Add notifications feed and unread counters.
- Add weekly digest email for city activity.
- Add referral links and invite codes.

## Phase D: Distribution and traffic
- Add public city and community landing pages for SEO.
- Add structured metadata per city/community/post.
- Add social share cards for posts and profiles.

## Phase E: Reliability and scale
- Add Sentry, product analytics, and funnel dashboards.
- Add rate limits for auth, posting, and messaging.
- Add periodic DB maintenance and query performance reviews.
