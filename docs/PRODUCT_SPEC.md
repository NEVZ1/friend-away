# PRODUCT_SPEC

## Product name
FriendAway

## Concept
A free social platform for people living abroad.

## Users
- immigrants
- international students
- expats
- digital nomads

## Core use case
A person moves to a new city and wants to:
- find people like them
- ask practical questions
- share experiences
- join city and identity-based communities
- message others directly

## Main screens
- Home
- Communities
- Discover
- Messages
- Profile

## Core MVP features
1. Auth
2. Onboarding
3. Profiles
4. City feed
5. Posts + comments
6. Communities
7. Direct messaging
8. Discover recommendations

## Feed logic
Default feed = posts from the user's current city ordered by newest first.

## Cold start features
- suggested onboarding questions
- people like you
- auto-generated communities
- arrival cohorts

## Future features
- events
- housing
- jobs
- referrals
- local guides
