# UI_SYSTEM

## Design direction
Modern, minimal, polished social SaaS.
Inspiration level: Notion / Linear cleanliness, but warmer.

## Palette
- primary: #4F46E5
- secondary: #38BDF8
- accent: #22C55E
- background: #F8FAFC
- card: #FFFFFF
- border: #E2E8F0
- text-primary: #0F172A
- text-secondary: #475569
- text-muted: #94A3B8

## Layout
- mobile-first
- bottom tab nav
- max-width containers for desktop
- large white cards
- generous spacing
- subtle hover states

## Component styling
- cards: white, 12px radius, soft shadow
- buttons: rounded, bold, clear hierarchy
- inputs: subtle borders, strong focus ring
- avatars: circular
- tabs: icon + label
- feed cards: avatar, metadata, content, actions

## Interaction
- smooth hover transitions
- subtle active states
- skeleton loaders where possible
